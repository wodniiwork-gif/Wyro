# Wyro — ИИ-помощник для Ray-Ban Meta (by Art Anzhelii)

Приложение для iPhone: говоришь в очки «Клод, что это?», оно берёт кадр с камеры очков,
отправляет его Claude вместе с вопросом и зачитывает ответ в динамики очков.

Работает через официальный набор Meta (Wearables Device Access Toolkit 1.0.1).
Поддерживаются Ray-Ban Meta Gen 1 и Gen 2.

---

## Что понадобится

- iPhone (у тебя iPhone 15 — подходит) и кабель для ПК
- Очки, подключённые к приложению **Meta AI** (обнови и приложение, и прошивку очков)
- Аккаунт на **GitHub** (бесплатно)
- Ключ API Claude с **console.anthropic.com** (платно, по запросам; пополни баланс на $5–10)
- Программа **Sideloadly** на Windows (sideloadly.io) и **iTunes** с сайта Apple (не из Microsoft Store), чтобы ПК видел iPhone
- Обычный Apple ID

## Шаг 1. Собрать приложение на GitHub (Mac не нужен)

1. Зайди на github.com → **New repository** → имя `ClaudeGlasses` → **Private** → Create.
2. Нажми **uploading an existing file** и перетащи **всё содержимое** этой папки
   (включая папку `.github` — без неё сборки не будет). Нажми **Commit changes**.
   Проверь, что в репозитории появилась папка `.github/workflows`. Если её нет (браузер иногда
   пропускает папки с точкой): **Add file → Create new file**, имя `.github/workflows/build.yml`,
   вставь содержимое файла `build.yml` из архива → Commit.
3. Открой вкладку **Actions**. Сборка «Build iOS app» запустится сама (если нет — выбери её и нажми **Run workflow**).
4. Через 5–15 минут появится зелёная галочка. Открой сборку и внизу в **Artifacts** скачай `ClaudeGlasses-ipa`.
   Это zip — распакуй, внутри `ClaudeGlasses.ipa`.

**Если красный крестик:** скачай артефакт `build-log` и пришли мне строки с `error:` — починим.

> Бесплатных минут GitHub для приватных репозиториев хватает на несколько сборок в месяц
> (Mac-минуты считаются ×10). Если закончатся — сделай репозиторий публичным: тогда бесплатно без лимита.
> Ключ API в код не зашит, так что это безопасно.

## Шаг 2. Установить на iPhone

1. Подключи iPhone кабелем, на телефоне нажми «Доверять этому компьютеру».
2. Открой Sideloadly, перетащи туда `ClaudeGlasses.ipa`, введи свой Apple ID, нажми **Start**.
3. На iPhone: **Настройки → Основные → VPN и управление устройством** → нажми на свой Apple ID → **Доверять**.
4. На iPhone включи **Режим разработчика**: Настройки → Конфиденциальность и безопасность → Режим разработчика (телефон перезагрузится).

> С бесплатным Apple ID приложение работает **7 дней**. Потом снова открой Sideloadly и нажми Start —
> данные и ключ сохранятся.

## Шаг 3. Включить режим разработчика в Meta AI

1. В приложении Meta AI: **Настройки → О приложении (App Info)** → нажми на **номер версии 5 раз**.
2. Включи **Developer Mode** → **Enable**.

## Шаг 4. Первый запуск

1. Открой Wyro. Откроются настройки — вставь ключ API (`sk-ant-…`).
2. Нажми **Подключить очки** → откроется Meta AI → подтверди → вернись в приложение.
3. Надень очки и нажми **Запустить камеру и звук**. Первый раз Meta AI спросит разрешение на камеру —
   выбери «Разрешать всегда». iPhone спросит про микрофон и распознавание речи — разреши.
4. Готово:
   - **«Спросить сейчас»** — задай один вопрос голосом.
   - **«Слушать всегда»** — говори «Клод, сколько это может стоить?» в любой момент.
   - Одиночный тап по дужке очков ставит камеру на паузу, долгое нажатие — выключает.

## Режимы

Переключатель вверху экрана или голосом: «Клод, режим барбера / артиста / стилиста», «Клод, обычный режим».

**Обычный** — покупки и мелочи по жизни. «Клод, что это и сколько стоит?», «Клод, какой из двух лучше?»,
«Клод, что тут написано?» (переведёт письмо, документ, меню с английского).

**Барбер** — наставник по стрижке. «Клод, где линия?», «Клод, как убрать вот это?», «Клод, есть ступеньки?».
Смотри на нужную зону 1–2 секунды, держись на 40–60 см, нужен хороший свет.
Переводчик для англоязычных клиентов (работает в любом режиме):
- «Клод, слушай клиента» (или кнопка «Перевести клиента») → клиент говорит по-английски → ты слышишь перевод в очках;
- «Клод, скажи клиенту: сверху оставить подлиннее?» → айфон произносит это **вслух по-английски** через свой динамик;
- «Клод, как сказать …» → английская фраза только тебе в очки.
Микрофон очков лучше всего слышит тебя, поэтому клиент пусть говорит ближе к очкам или к телефону.

**Артист** — соавтор и звукорежиссёр. «Клод, рифма к …», «Клод, почему сырая строчка: …», «Клод, нужен хук про …»,
«Клод, вокал тонет в бите, что делать?», «Клод, хэштеги под трек». Покажи экран с микшером: «Клод, смотри на микшер, что не так?».
Блокнот: «Клод, запомни строчку …», «Клод, прочитай строчки», «Клод, удали последнюю строчку»; кнопка «Блокнот строчек» — список, копирование, поделиться.
В этом режиме кадр с камеры отправляется, только если ты говоришь «смотри / это / экран / микшер» — так дешевле.

**Стилист** — смотри на вещь или в зеркало. «Клод, как эта вещь?», «Клод, сочетается образ?» (оценка из 10 и что поправить),
«Клод, с чем это носить?», «Клод, какую из двух брать?», «Клод, собери образ на концерт».

Между клиентами или темами нажимай «Новый разговор» в настройках.

## Если что-то не работает

| Проблема | Что делать |
|---|---|
| «Не удалось подключить очки» | Проверь, что Developer Mode в Meta AI включён и очки подключены к Meta AI |
| Камера «ждёт очки…» | Надень очки, открой дужки, держи Meta AI запущенным в фоне |
| Камера не включается вообще | Пришли мне текст ошибки. Возможная причина — бесплатный Apple ID не даёт приложению Wi-Fi-доступ, тогда попробуем другой режим |
| Не слышит вопрос | Говори чётко «Клод», потом вопрос, потом пауза 1,5 сек |
| Ответ звучит глухо | Это нормально: пока микрофон очков включён, Bluetooth передаёт звук в «телефонном» качестве |
| «Ошибка Claude (401)» | Неверный ключ API |
| «Ошибка Claude (400) … credit» | Пополни баланс на console.anthropic.com |

## Сколько стоит

Один вопрос с картинкой обычно стоит порядка цента-двух; на Haiku дешевле, чем на Sonnet
(переключается в настройках). Точные цены — на странице Pricing в console.anthropic.com. Кадр отправляется **только когда ты спрашиваешь**, не постоянно.

## Важно

- Набор Meta пока в режиме превью, поэтому возможны баги — шли ошибки, будем чинить.
- Приложение ничего не покупает само: только подсказывает.
- Камера на лице — чувствительная штука: не снимай людей без их согласия.
